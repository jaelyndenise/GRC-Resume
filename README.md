# Jaelyn Denise — Portfolio & Resume

A single-page, glassmorphism portfolio site for Jaelyn Denise — CISSP, security engineer,
GRC specialist, and full-stack developer.

**Live site:** https://jaelyndenise.github.io/GRC-Resume/

## Structure

- `docs/` — the site, served by GitHub Pages (`index.html`, `style.css`, `script.js`)
- `docs/assets/` — photos, project screenshots, and fonts

## Features

- Galaxy midnight theme with twinkling starfield, plus a light "daybreak" mode
  (sun/moon toggle, persisted in `localStorage`)
- One-page scroll with deep links: Why Me · Experience · Projects · Skills ·
  Writing · Beyond the Desk · Contact
- No build step — plain HTML/CSS/JS

## Branches

- `main` — live site
- `original` — snapshot of the pre-redesign multi-page site
